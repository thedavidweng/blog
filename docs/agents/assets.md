# Article and generated assets

- Commit manually pre-optimized article AVIF files under `public/posts/<slug>/`, not `src/`, so Astro serves them without re-encoding. See the [image workflow](../image-workflow.md) for conversion procedures and [ADR-0001](../adr/0001-public-images.md) for rationale.
- Build-time Open Graph images are generated by `astro-og-canvas` into `dist/og/`. Do not commit the generated files to `public/og/`. The empty directory is intentional.
- Review `pnpm run check:images` and generated asset behavior when image paths or pipelines change.
